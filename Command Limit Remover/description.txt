[h1]Features[/h1]
This mod effectively removes the command limit for fleets by setting it to 20000 from the start of the game :o

[h1]Compatibility[/h1]
This mod overrides the two defines for COMMAND_LIMIT_MAX and COMMAND_LIMIT_BASE but shouldn't have any compatibility issues with other mods :)
